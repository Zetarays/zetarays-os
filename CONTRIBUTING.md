# Contributing to ZETA RAYS OS

Thank you for helping. A few simple rules keep the system consistent.

1. **Open an issue first** for anything bigger than a typo, so we can agree on
   the idea before you spend time on it.
2. **One change per pull request**, with a short description of *why*.
3. **Test it**: build the image you touched (`./build.sh arm64` or `amd64`,
   see `docs/BUILD.md`) or at least run the checks that run on every pull
   request (shell syntax, Python, firewall syntax).
4. **Keep the style**: the system speaks Italian to the user; comments explain
   *why*, not *what*; no em dashes in texts shown to users.
5. **No secrets, no personal data** in commits: API keys, passwords, IP
   addresses of your machines.
6. **Licences**: new code is GPL-3.0-or-later. Do not add fonts, images or
   other files whose licence does not allow redistribution.

## In italiano

Apri prima una *issue*, una modifica per *pull request*, prova quello che
cambi, niente chiavi né dati personali, e solo file che si possono
ridistribuire.
